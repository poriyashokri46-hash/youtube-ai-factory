# کارخانه هوش مصنوعی یوتیوب (YouTube AI Factory)

اپلیکیشن بومی اندروید برای مدیریت پروژه‌های ویدئویی و رندر محلی MP4 با MediaCodec و MediaMuxer. توجه: این پروژه هنوز کامل نیست؛ وجود رابط کاربری به معنی پیاده‌سازی سرویس واقعی نیست.

---

## وضعیت واقعی قابلیت‌ها (شفاف‌سازی)

این پروژه در حال توسعه است. وضعیت فعلی قابلیت‌ها:

- **مدیریت پروژه‌ها:** ذخیره محلی پروژه‌ها با Room.
- **رندر MP4:** کد رندر محلی وجود دارد و مسیر ترکیب صدای AAC/M4A با ویدئو در مرحلهٔ جداگانه اصلاح شده است؛ هنوز روی دستگاه واقعی آزمایش نشده است. تولید گفتار محلی با موتور Text-to-Speech نصب‌شده روی دستگاه اضافه شده است؛ صدای خروجی و پشتیبانی فارسی/انگلیسی به موتور و داده‌های نصب‌شده بستگی دارد. فایل گفتار به AAC/M4A تبدیل می‌شود؛ این مسیر هنوز روی دستگاه واقعی آزمایش نشده است.
- **سناریونویسی:** مسیر درخواست واقعی Gemini API اضافه شده است و کلید API را کاربر در صفحه استودیو وارد می‌کند. کلید فقط در حافظه همان اجرای برنامه نگه‌داری می‌شود و ذخیره نمی‌شود؛ پس از بستن برنامه باید دوباره وارد شود. این تغییر هنوز روی دستگاه/با ساخت نهایی آزمایش نشده است. سهمیه و شرایط رایگان Gemini به حساب و سیاست‌های Google بستگی دارد.
- **اتصال و انتشار یوتیوب:** جریان مجوز Google Identity با مجوزهای YouTube، دریافت کانال و آپلود resumable از طریق YouTube Data API پیاده‌سازی شده‌اند. برای استفاده واقعی باید در Google Cloud، YouTube Data API v3 را فعال و OAuth Client اندروید را با package ID و SHA-1 دقیق برنامه ثبت کنید. توکن فقط در حافظه است و بعد از راه‌اندازی مجدد باید دوباره متصل شوید؛ این مسیر هنوز روی دستگاه واقعی و حساب دارای مجوز آزمایش نشده است.
- **آمار یوتیوب:** درخواست واقعی YouTube Analytics API برای بازدیدها، زمان تماشا، مشترکین جدید، میانگین درصد مشاهده و منابع ترافیک اضافه شده است. تا زمانی که کاربر متصل و دکمهٔ به‌روزرسانی را نزده باشد، مقدارها خالی می‌مانند. نیازمند فعال‌سازی API و مجوز مناسب است و هنوز روی دستگاه/کانال واقعی آزمایش نشده است.
- **اتوماسیون زمان‌بندی‌شده:** اجرای واقعی WorkManager یا ورکر ابری هنوز پیاده‌سازی نشده است.
- **ساخت APK/AAB:** گردش‌کار GitHub Actions برای ساخت بسته‌ها تعریف شده است؛ موفقیت هر ساخت را باید از نتیجه واقعی همان اجرای Actions بررسی کرد.

برای استفاده از تولید سناریوی Gemini، یک کلید API معتبر لازم است. کلید را در مخزن عمومی یا پیام‌های عمومی قرار ندهید؛ در برنامه فقط برای درخواست مستقیم به Google استفاده می‌شود و در حافظه محلی ذخیره نمی‌شود. محدودسازی کلید و سهمیه را در کنسول ارائه‌دهنده بررسی کنید. سایر سرویس‌ها همچنان به تنظیمات واقعی ارائه‌دهنده و مجوزهای لازم نیاز دارند.

## پیش‌نیازهای تکمیل قابلیت‌های آنلاین

این موارد عمداً از هم جدا هستند؛ داشتن کلید Gemini به معنی اتصال یوتیوب نیست.

### تولید سناریو با Gemini
1. از Google AI Studio یک کلید API معتبر بسازید.
2. برنامه را اجرا کنید و در صفحهٔ استودیو، موضوع و کلید را وارد کنید.
3. در صورت خطای 400/403، مدل در دسترس پروژه، فعال بودن API و محدودیت‌های کلید را بررسی کنید؛ در صورت 429 سهمیه یا محدودیت نرخ درخواست تمام شده است.
4. کلید در این پیاده‌سازی فقط در حافظهٔ ViewModel است، اما هر کلیدی که در اپ موبایل استفاده شود در برابر کاربرِ دارای دسترسی به دستگاه کاملاً محرمانه محسوب نمی‌شود. برای انتشار عمومی، پراکسی سمت سرور با کنترل سوءاستفاده امن‌تر است.

### انتشار و آمار یوتیوب
برای استفاده از اتصال و انتشار، در Google Cloud یک پروژه بسازید، YouTube Data API v3 و YouTube Analytics API را فعال کنید، صفحهٔ رضایت OAuth را تنظیم کنید و OAuth Client از نوع Android را با شناسهٔ بستهٔ دقیق `com.aistudio.ytaifactory.kznqvx` و SHA-1 گواهی امضای همان build ثبت کنید. مجوزهای OAuth شامل آپلود و خواندن اطلاعات کانال/آمار است. آپلود از پروتکل resumable استفاده می‌کند؛ خطاهای سهمیه، تأیید برنامه یا API غیرفعال از پاسخ واقعی گوگل نمایش داده می‌شوند. توکن در حافظه نگه‌داری می‌شود و پس از بستن کامل برنامه باید دوباره متصل شوید.

### خروجی ویدئو
رندر فعلی ویدئوی تصویری MP4 را به‌صورت محلی تولید می‌کند. صدای انتخاب‌شده باید از نوع AAC/M4A سازگار با MP4 باشد؛ این کد صدای گفتاری هوش مصنوعی تولید نمی‌کند. سرعت گفتار در تولید TTS اعمال می‌شود؛ انتخاب سبک/جنس صدا هنوز به‌طور کامل به صداهای موتور دستگاه نگاشت نشده است. عملکرد رندر، همگام‌سازی صدا، ذخیره در گالری و پایداری روی نسخه‌های مختلف Android هنوز نیازمند آزمایش نهایی روی دستگاه است.

### اتوماسیون
زمان‌بندی واقعی تا پیاده‌سازی Worker، مدیریت مجوزها/محدودیت‌های اجرای پس‌زمینهٔ Android و اتصال امن به جریان تولید/انتشار تکمیل نشده است. این گزینه فعلاً عمداً خاموش است.

## نحوه ساخت و دریافت APK از طریق GitHub Actions (بدون نیاز به اندروید استودیو)

برای کاربران گوشی‌های اندرویدی و کسانی که از مرورگر موبایل یا Termux استفاده می‌کنند:

### روش ۱: استفاده از مرورگر موبایل در گیت‌هاب (Mobile Browser)

1. مخزن (Repository) خود را در سایت GitHub با مرورگر گوشی باز کنید.
2. به زبانه **Actions** بروید.
3. گردش‌کار **"Build YouTube AI Factory Android App"** را انتخاب کنید.
4. روی دکمه **Run workflow** کلیک کنید تا فرآیند ساخت آغاز شود.
5. پس از پایان ساخت (علامت تیک سبز)، روی عنوان بیلد کلیک کنید و در بخش پایین صفحه (بخش **Artifacts**):
   * فایل **`YouTube-AI-Factory-APK`** را دانلود کنید (حاوی فایل نصبی APK).
   * فایل زیپ را در گوشی اکسترکت کرده و APK را مستقیماً نصب کنید.

### روش ۲: استفاده از خط فرمان یا Termux

```bash
# نصب بسته گیت و ابزارهای لازم در ترموکس
pkg install git gh -y

# کلون مخزن
git clone <URL_REPOS_شما>
cd <نام_پوشه_پروژه>

# اعطای مجوز اجرایی به گرادل
chmod +x gradlew

# تست کامپایل محلی در صورت وجود OpenJDK
./gradlew assembleDebug
```

## ساختار ماژول‌ها و کتابخانه‌ها

* **Video Renderer**: انکودینگ فریم‌های تصویری و زیرنویس با `android.media.MediaCodec` به همراه ترکیب استریم صوتی و خروجی استاندارد MP4 با `android.media.MediaMuxer`.
* **Video Player**: پخش‌کننده روان `androidx.media3:media3-exoplayer` با کنترل‌های کامل کاربری.
* **Database**: پایگاه داده محلی پایدار `androidx.room` نسخه ۲ جهت ذخیره پروژه‌ها، سناریوها و وظایف اتوماسیون.
* **UI**: ۱۰۰٪ با **Jetpack Compose** بر پایه Material 3 با تم اختصاصی سرمه‌ای-فیروزه‌ای و پشتیبانی دوطرفه از زبان‌های راست‌به‌چپ (فارسی) و چپ‌به‌راست (انگلیسی).
